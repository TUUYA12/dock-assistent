# AI-Agent Dock-Assistent (RAG + Локальный ML)

Автономный ИИ-агент на базе гибридной архитектуры, включающей локальное семантическое ядро **RuBERT**, кастомную **RAG-систему** (Retrieval-Augmented Generation), интегрированный классификатор **SGDClassifier** (из исходного ML-модуля) и бэкенд на **FastAPI**. 

Агент выполняет интеллектуальный контекстный анализ сюжетов из подготовленного датасета и генерирует точные текстовые ответы через API-ключ **GigaChat**, обходя любые сетевые прокси-блокировки Windows.

---

## 🚀 Ключевые особенности и архитектура

1. **Двухэтапный конвейер (Пайплайн) обработки запроса**:
   - **Локальный ML-фильтр (`main.py`)**: Предварительно обученные модели `HashingVectorizer` и `SGDClassifier` моментально категоризируют жанровую направленность вопроса пользователя.
   - **Семантический поиск (RuBERT + FAISS)**: Локальная эмбеддинг-модель `DeepPavlov/rubert-base-cased` осуществляет высокоточный поиск по векторам описаний сюжетов в оперативной памяти (с поддержкой аппаратного ускорения **NVIDIA CUDA GPU**).
2. **Динамический шлюз GigaChat API**: Сервер при старте автоматически опрашивает облако Сбера, выявляет доступные текстовые модели вашего тарифа (например, `GigaChat-2`) и на лету подстраивает вызовы, полностью защищая систему от `404` ошибок при обновлении линеек моделей.
3. **Сетевой иммунитет**: В код бэкенда внедрена жесткая изоляция процесса Python от системных прокси-серверов, VPN-клиентов и перехватчиков сетевого стека Windows (LSP/Tun/Tap), что решает проблему блокировок `403 Forbidden` и обрывов сокетов.
4. **Кросс-платформенное кодирование**: Корректная обработка UTF-8 / CP1251 для бесшовной интеграции ответов как в современные веб-интерфейсы, так и в классическую консоль Windows PowerShell.

## ⚙️ Инструкция по развертыванию и запуску

### 1. Подготовка окружения
Установите зависимости в ваше виртуальное окружение:
```bash
pip install -r requirements.txt
```

Создайте в корневом каталоге файл **`.env`** и укажите ваш секретный ключ авторизации Сбера:
```env
GIGACHAT_CREDENTIALS="Ваш_Клиент_Айди_Токен_От_Сбера"
```

### 2. Запуск локального сервера Агента
Запустите бэкенд-сервер через `uvicorn`. Он автоматически подтянет локальные ML-модели, инициализирует RuBERT и подключится к облачному генератору:
```bash
uvicorn src.app:app --host localhost --port 8000 --reload
```

### 3. Тестирование запросов
Запросы можно отправлять из любого внешнего клиента. Пример отправки через встроенный отладочный скрипт:
```bash
python test_request.py
```

Пример отправки напрямую из **Windows PowerShell**:
```powershell
\$Body = '{"question": "Найди фильм про космическую экспедицию к Марсу и расскажи его сюжет", "k": 1}'
\$Response = Invoke-RestMethod -Method Post -Uri "http://localhost:8000/ask" -Body \$Body -ContentType "application/json; charset=utf-8"
\$Response.answer
```

## 🐳 Контейнеризация (Docker)

Проект полностью готов к деплою на внешние сервера в изолированном виде. Сборка Docker-образа осуществляется командой:
```bash
docker build -t dock-assistent-agent .
```
