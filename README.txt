# 🎬 AI-Agent Dock-Assistent: Гибридная RAG-система, MLOps и Агентные циклы

Автономный ИИ-агент для интеллектуального поиска, аналитики рейтингов и пересказа сюжетов по локальной базе кинофильмов (`41 000+` записей). 

Проект объединяет **классическое машинное обучение (TF-IDF + LinearSVC)**, **кастомную RAG-архитектуру (Retrieval-Augmented Generation)** на базе **FastAPI + GigaChat API**, **MLOps-конвейер (MLflow Model Registry)** и **сравнение трёх архитектур ИИ-агентов** с вызовом инструментов.

---

## 🧠 Архитектура и логика работы (Что, где и почему)

Система разделена на **4 независимых слоя**, каждый из которых решает конкретную инженерную задачу:

### 1. Слой машинного обучения и подготовки весов (`train_weights.py`)
* **Зачем это нужно:** Искать смысловые совпадения по всей базе из 41 000 фильмов долго и шумно. Локальный ML-классификатор мгновенно определяет **Top-2 вероятных жанра** запроса пользователя и отсекает нерелевантную часть базы.
* **Как реализовано:**
  * Проведена очистка текстов от HTML/CSS-мусора Википедии (`mwparseroutput`) и приведение 845 пересекающихся тегов к **7 чётким макро-жанрам**.
  * Внедрён морфологический стеммер (`stem_russian_text`), отрезающий падежные и глагольные окончания, чтобы слова *«убийца»*, *«убийство»* и *«убийцей»* имели единый корень.
  * Обучен пайплайн **`TfidfVectorizer` (100 000 признаков, униграммы и биграммы) + `CalibratedClassifierCV(LinearSVC)`**.
* **Результат:** Строгая точность **Top-1 = 74.43%**, точность попадания в 2 главных жанра **Top-2 = 90.43%**. Веса сохранены в `hashing_vectorizer.pkl` и `genre_classifier_model.pkl`.

### 2. Слой RAG и REST API бэкенд (`src/app.py` и `src/rag.py`)
* **Зачем это нужно:** Предоставить единый HTTP-интерфейс (`POST /ask`) и исключить галлюцинации языковой модели, заставив её отвечать **строго по фактам из локального датасета**.
* **Как реализовано:**
  * **ИИ-маршрутизатор (`rag_answer`):** GigaChat анализирует запрос пользователя и определяет намерение: нужна ли **аналитическая сортировка по рейтингу IMDb** (например, *«фильмы с лучшими оценками»*), **расширение ассоциативного запроса** (*«фильм, похожий на Во все тяжкие»* -> генерация сюжетных тегов) или **прямой поиск по сюжету**.
  * **Фильтрация и ранжирование:** Запрос фильтруется через веса `LinearSVC`, затем ранжируется по уникальным смысловым корням слов в описаниях (`summary` + `plot`).
  * **Защита от галлюцинаций и сетевых сбоев:** Системный промпт строго запрещает LLM выдумывать фильмы вне переданного контекста. В `src/app.py` реализована изоляция переменных прокси (`NO_PROXY`) и динамическое определение доступной модели Сбера (`GigaChat-2`).

### 3. MLOps-конвейер и реестр моделей (`mlops_train.py`)
* **Зачем это нужно:** Автоматизировать подбор гиперпараметров, сохранение артефактов (графиков точности, весов) и версионирование моделей.
* **Как реализовано:**
  * Настроено локальное хранилище экспериментов **MLflow (`sqlite:///mlflow.db`)**.
  * Прогнана серия из **4 экспериментов** с разными значениями регуляризации `C` и размера словаря `max_features`.
  * Для каждого запуска логируются метрики (`test_accuracy_top1`, `test_accuracy_top2`), теги, график сравнения `accuracy_chart.png` и сериализованный `Pipeline`.
  * Лучшая модель автоматически зарегистрирована в **MLflow Model Registry** под именем **`FilmGenreClassifier`** и переведена в стадию **`Staging`**.

### 4. Автономные агентные циклы и Tool Calling (`agents_comparison.py`)
* **Зачем это нужно:** Научить агента решать **составные многошаговые задачи** (например: *«Узнай средний рейтинг комедий, средний рейтинг ужасов и вычисли разницу между ними»*), самостоятельно выбирая и вызывая внешние функции.
* **Реализованы 3 инструмента:**
  1. `search` — поиск фильмов и сюжетов в базе.
  2. `stats` — подсчёт количества фильмов и среднего рейтинга IMDb по жанру.
  3. `calc` — безопасный AST-калькулятор для математических вычислений.
* **Сравнение 3 архитектурных подходов:**
  1. **Ручной JSON-цикл (`run_json_agent`):** Модель возвращает строго структурированный JSON (`{"tool": "...", "arg": "..."}`), парсер `JSONDecoder.raw_decode` извлекает команду, выполняет её и передаёт результат в историю следующего шага.
  2. **Native Tool Calling (`run_native_agent`):** Передача JSON-схем (`TOOL_SCHEMAS`) через `llm.bind_tools()` и ручная обработка `tool_calls` с возвратом `ToolMessage` по `tool_call_id`.
  3. **Фреймворк LangGraph (`run_framework_agent`):** Автоматическая оркестрация ReAct-агента через `create_react_agent`.

## 📂 Структура репозитория

```text
dock-assistent/
├── src/
│   ├── app.py                     # FastAPI-сервер (эндпоинт POST /ask, изоляция прокси)
│   └── rag.py                     # Ядро RAG: маршрутизатор, фильтр по весам, поиск по IMDb и сюжетам
├── train_weights.py               # Обучение и калибровка LinearSVC + TF-IDF (90.43% Top-2)
├── mlops_train.py                 # MLOps-пайплайн: 4 запуска в MLflow, графики, регистрация в Staging
├── agents_comparison.py           # Сравнение 3 агентных циклов (JSON, Native Tool Calling, LangGraph)
├── test_request.py                # Клиентский скрипт для отправки тестовых запросов к API
├── Dockerfile                     # Конфигурация сборки изолированного Docker-контейнера
├── requirements.txt               # Список зависимостей проекта
└── .gitignore                     # Исключение тяжелых датасетов (.csv), весов (.pkl), БД (mlflow.db) и .env
```

## 🚀 Инструкция по запуску и демонстрации

### 1. Установка зависимостей и настройка ключа
```bash
pip install -r requirements.txt
```
Создайте в корне файл `.env` и добавьте авторизационный ключ GigaChat:
```env
GIGACHAT_CREDENTIALS="Ваш_Токен_Авторизации_Сбера"
```

### 2. Запуск основного RAG-сервера и проверка API
В первом терминале запустите веб-сервер:
```bash
uvicorn src.app:app --host localhost --port 8000 --reload
```
Во втором терминале отправьте тестовый запрос:
```bash
python test_request.py
```

### 3. Демонстрация MLOps и реестра моделей (MLflow)
Запустите серию экспериментов и откройте веб-интерфейс MLflow:
```bash
python mlops_train.py
mlflow ui --backend-store-uri sqlite:///mlflow.db
```
Веб-интерфейс будет доступен по адресу: **`http://127.0.0.1:5000`** (разделы *Training runs*, *Artifacts* и *Model registry* со статусом `Staging`).

### 4. Демонстрация 3 подходов ИИ-агентов
```bash
python agents_comparison.py
```
В консоли отобразится пошаговая трассировка вызовов инструментов (`stats` -> `stats` -> `calc`) для ручного JSON-агента, Native Tool Calling и LangGraph.
